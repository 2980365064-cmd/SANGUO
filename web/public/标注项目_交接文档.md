```json
{
  "provincePoints": {
    "益州": [{ "x": 608, "y": 695 }, { "x": 619, "y": 685 }, ...],

  },
  "cityPoints": {
```

## 🛠️ 技术栈

- **前端**: React + TypeScript + Vite
- **地图**: SVG 路径渲染
- **标注工具**: 纯 HTML/JS（无框架依赖）
- **数据存储**: localStorage + JSON 文件

---

## 📌 注意事项

1. **路径生成**: 使用极角排序算法（按角度从中心点排序），避免路径交叉
2. **重复点**: 已清理，每个坐标只保留一个点
3. **共享边界**: 相邻州/城池共享边界点，减少标注工作量
4. **数据同步**: 标注工具点击"同步"按钮可将数据保存到 `annotation_data.json`
