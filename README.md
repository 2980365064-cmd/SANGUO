# 汉祚再兴 · 刘备传

一款从建安十三年（208）赤壁前夕开始、以刘备为唯一玩家视角的 AI 对话式三国政略游戏。

玩家通过召见人物、核定军令、处理外交、推进国策和经营地区改变历史。大模型负责人物对话与叙事表达；人物死亡、领土易主、军队覆灭、违约后果、历史事件和结局全部由结构化动作与硬规则确认。

## 当前内容

- 时间：208 年 8 月至 223 年 4 月，每回合一个月。
- 地图：13 州、49 个战略节点、79 条双向边；前端以州块与郡域为主交互。
- 开局：9 方势力、25 支独立军队、刘备三军共 22,000 人。
- 人物：140 名历史人物，均有六维、五项动态人格、势力、所在地、状态、官职、核心等级、规则特性和登场窗口。
- 历史压力：15 张刘备主线历史事件卡，可按当前世界状态发生、改写、被替代或失效。
- 结局：刘备死亡、益州核心失守、政权瓦解、白帝历史终局、223 改写收束、一统胜利。

## 核心规则

- 每支军队每月只能执行一道主军令：移动、驻守、围城、突袭、补给或撤退。
- 行军按州块验证：同州或相邻州可行动，一次行动消耗一个月；路线表仅作为州邻接兼容事实源。
- 关隘、江河和山道不再作为普通移动入口的前台路线机制；围城、补给和战役仍由结构化硬规则校验。
- 战役按 60% 硬规则和 40% 白名单计策裁决，公开随机值、属性、特性、补给和地形修正。
- 外交分别保存公开关系、互信、盟约义务、领土主张、婚姻/人质和军事协作；违约必然结算代价。
- 人物能力和人格必须同时影响结算、AI 上下文与审计日志。

## 运行

要求 Python 3.11 与 Node.js。

```bash
python3 -m pip install -r requirements.txt
cd web
npm ci
npm run build
cd ..
python3 web_app.py
```

开发模式也可运行：

```bash
cd web
npm run dev
```

后端默认由 `web_app.py` 提供 FastAPI；桌面入口为 `launcher.py`。

## 测试

```bash
python3 -m pytest tests -q
cd web && npm ci && npm run build
```

发布前还应验证：新局、完整月末、手动存档/读档、自动存档轮转、223 结局，以及凭空援军、越关、低粮险行、同军双令和无代价违约等对抗用例。

## 主要目录

- `content/`：三国静态事实源与运行时提示词。
- `ming_sim/`：数据库、会话、人物、战略、补给、围城、战役、外交、国策、事件、外部 AI 与结局规则。
- `web/src/`：React 地图、军令面板、HUD、时间线、人物、外交、国策、家族和史册界面。
- `tests/`：硬规则、API、迁移、完整月末和对抗性测试。
- `docs/superpowers/plans/`：实施计划与恢复点。

## 存档版本

新存档写入：

```text
scenario_id=sanguo_liubei_208
```

首次启动自动创建新存档，场景 id 标记为 `sanguo_liubei_208`。每局保留手动存档与最近三个回合的自动存档。

## 仍保留的内部兼容命名

以下名称仅用于包路径或通用引擎模块名，不进入玩家可见状态合同：

- Python 包名 `ming_sim`。
- 环境变量前缀 `MING_SIM_*`。
- 数据库文件名 `ming_sim.db`。
