# 查询工具集架构设计 v2

> **替代裁决包（Adjudication Pack）方案**
> **核心原则**：AI 按需查询数据，而不是被喂固定数据包

---

## 一、问题回顾

### 裁决包方案的瓶颈

```
玩家说"派细作散布谣言"
    ↓
系统构建裁决包 → 只能塞入预定义字段（兵力/地形/天气/统帅属性）
    ↓
AI 裁决 → 但看不到曹操阵营稳定性、情报网络、内部派系矛盾等
    ↓
AI 判断不准度受限于"系统认为需要给什么数据"
```

**根本问题**：数据组合是无限的，不可能预定义所有可能的字段。

### 查询工具集方案

```
玩家说"派细作散布谣言"
    ↓
AI 裁决 Agent 启动，持有查询工具集
    ↓
AI 分析需要什么数据 → 调用 query_faction_internal("曹操")
    ↓
AI 分析还需要 → 调用 query_intelligence_network("许昌")
    ↓
AI 基于真实数据推演 → 输出有界结果
    ↓
校验器验证边界 → 通过则落库
```

## 三、裁决 Agent 架构

### 3.1 新流程

```
玩家自由意图（自然语言）
    ↓
创建裁决 Agent（agno Agent）
    ├── 指令：你是 SANGUO 裁决员，基于查询到的真实数据评估玩家方案
    ├── 工具：查询工具集（只读）
    ├── 约束：delta 边界、禁止字段、事实一致性
    └── 玩家意图：作为初始 prompt
    ↓
Agent 自主查询 → 收集数据 → 评估可行性 → 输出 JSON
    ↓
校验器验证边界
    ├── 通过 → 落库执行
    └── 越界 → 裁剪或 pending_review
```

### 3.2 Agent 配置

```python
adjudicator = Agent(
    name="SANGUO裁决员",
    model=create_chat_model(...),
    tools=ALL_QUERY_TOOLS,  # 查询工具集
    instructions=[
        "你是 SANGUO 的裁决员。",
        "基于查询到的真实盘面数据评估玩家方案的可行性。",
        "不能编造不存在的条件。",
        "输出必须包含：feasibility, delta, reasoning, narrative。",
        "delta 必须在规则边界内。",
        "不能写死亡、领土变化、增兵等世界事实。",
    ],
)
```

### 3.3 查询次数限制

防止 Agent 无限查询：

```python
MAX_QUERIES_PER_ADJUDICATION = 15
```

## 四、安全边界

### 4.1 工具层

- 所有查询工具**只读**，不修改任何数据
- 查询结果必须来自数据库真实数据
- 不返回内部风险值或未确认情报（前端安全）

### 4.2 裁决层

- delta 边界硬裁剪
- 禁止字段/文本检查
- 事实一致性检查（Agent 声称的条件必须在查询结果中有依据）
- impossible 方案退回默认

### 4.3 审计层

- 记录 Agent 的所有工具调用
- 记录 Agent 的推理过程
- 记录最终输出和校验结果
- 可追溯、可复现
