# P1 接收验收报告

验收日期：2026-07-22  
范围：P1 的任免、战役、使臣、会盟、随机事件、方略批次、场景壳层，以及遗留即时写入入口。

## 验收结论

P1 的玩家主链路现以“草案 → 颁令批次 → 分阶段推演 → 每月总计”为唯一写入路径。旧接口仍保留 URL 或兼容导出时，会明确返回 `410 Gone` 或在浏览器端拒绝，不会写入世界。

## 有意保留的兼容表面

- 历史组件仍可从 `web/src/api.ts` 引用旧函数以保持 TypeScript 编译；这些函数只会返回“已弃用”的 rejected Promise，绝不发起写请求。
- 后端旧 URL 同样只用于让旧客户端获得可解释错误。它们不是后台写入通道。
- `previewBattle`、城池详情、使臣/条约列表、月报等仍为只读查询，不受此限制。

## 可复现验证

在仓库根目录执行：

```bash
PYTHONPATH=. pytest -q
```

在 `web/` 目录执行：

```bash
npm run build
node --test tests/*.test.ts
```

本次结果：后端 `203 passed`；前端构建通过；前端 `25 passed`。
