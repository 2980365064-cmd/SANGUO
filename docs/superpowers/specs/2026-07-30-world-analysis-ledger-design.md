# 天下推演录设计

## 页面职责

“天下推演录”是月度世界结果的只读分析与审计面。它展示经可见性过滤后的世界变化、情报可信度、区域战线和依据；不创建方略、不下令、不触发结算。

## 结构

1. 本月总断：当前月度最重要的可见结论。
2. 天下变局：将奏议、区域事件、外部情报和天下反应按可见时间次序写入因果线。
3. 势力研判：以“已证实 / 有据研判 / 商旅传闻”标记现有情报。
4. 区域战线：提炼区域事件的地区与摘要。
5. 推演依据：每条记录只展示来源、可信度与摘要，不展示隐藏权重或 true_subject_ref。

## 视觉

单张横向推演卷，左侧卷轴轴心，地图留作底层。总断、变局、研判、战线以文书分区和墨线连接；不使用行动栏、草案卡或现代数据面板。

## 边界

复用 `gameState.world` 与已有天下反应读取接口。页面不改 AI、随机、月度结算或事实写入规则，基线无需更新。
