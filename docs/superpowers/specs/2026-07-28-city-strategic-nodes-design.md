# 城池战略节点化设计

## 目标

以已经确定的 `州 → 郡 → 城` 地图名册作为唯一空间事实。每一座现役城池都是可驻军、行军、围城、战役与易主的独立战略节点；郡和州分别只承担行政汇总与派生控制权。

## 已确认边界

- 采用彻底迁移，不保留旧郡级 `strategic_nodes`、名称别名、前端临时坐标偏移或双节点兼容层。
- 现役城池目录由 `content/administrative_units.json` 唯一给出；退役城池不能有战略节点、路线、驻军或围城目标。
- 节点 ID 统一为城池 ID，例如 `city:jiangling`。`regions.id` 继续代表郡级事实，绝不再作为战略节点。
- 路线为城际 `strategic_routes`，行动必须走真实连接；不再将“同州/邻州”视为任意城池间可达。
- 旧档迁移必须确定性、幂等且可审计：旧郡节点上的驻军、围城和未结算军令目标转至该郡郡治城；不改变控制权、兵力、人口、库存、回合或随机记录。
- 本任务不引入随机、AI 新权限或新的月度阶段。既有硬规则只是把地点统一到城池节点。

## 数据结构

### 静态目录

1. `content/administrative_units.json`
   - 保留州、郡标签、现役城池和退役城池目录。
   - 每个现役城池必须有稳定 `city:*` ID、`commandery_id`、`province_id`、名称、郡治标记与静态角色。
   - 新增或复用一份明确的战略地理目录，提供每座现役城的地图锚点与城际边。不得再由前端推算坐标或以名称猜测归属。

2. `content/routes.json`
   - 只含现役 `city:*` 节点与它们之间的无向路线。
   - 每条路线端点必须是现役城池；路线类型沿用 `普通路 / 江河 / 山道 / 关隘`。
   - 不能存在重复、自连、退役节点或旧郡 ID。

### 存档

- `strategic_nodes` 的每行与 `administrative_cities.id` 一一对应；保存名称、州属和必要的地图位置来源。
- `strategic_routes` 只引用城池节点。
- `armies.station_node`、`sieges.target_node`、`army_orders.payload.to/target`、战役相关地点字段只能引用现役城池节点。
- `administrative_cities` 保持城池控制、城防、仓储与围城事实；`regions` 保持郡级人口、财政、民情和军压事实。

## 运行规则

1. `seed_static_data()` 以现役城目录增补/同步城池战略节点与路线，并清理已确认废弃的旧郡节点及其路线。
2. 迁移先解析旧节点到所属郡的郡治城；缺少可验证目标时中止并报出具体 ID，不能静默猜测。
3. 围城只接受城池节点；城权改变后继续由 `recompute_administrative_control()` 派生郡权与州权。
4. `sanguo_map_payload()` 直接从城池节点和行政事实输出：城池坐标为静态真实锚点，驻军按城池节点读取；不再返回伪造的郡节点或城市临时偏移。
5. 前端地图只消费节点 ID 与行政 ID 的同一套城池数据；删除名称别名、历史城镇“借用郡节点”和旧节点回退。

## API 合同

`/api/map` 返回：

- `nodes[]`：每项 ID 是 `city:*`，包含 `city_id`（同 ID）、`commandery_id`、`province_id`、真实坐标、城权与驻军。
- `cities[]`：可与 `nodes[]` 合并为同源视图，但不得再次产生独立地理坐标或不同驻军归属。
- `routes[]`：只返回有效城际路径。

## 错误处理与迁移审计

- 缺失的城市目录、节点、郡治或路线端点均为启动期错误，携带具体 ID。
- 迁移写入可查询的审计记录，至少包括旧 ID、新 ID、对象类型和原因。
- 对已经迁移的存档重复启动不得再次改写或重复记录。

## 验收与测试

1. 目录校验：所有现役城池节点一一对应；无退役城或旧郡节点残留；路线端点完整有效。
2. 迁移测试：旧郡驻军、围城及未结算军令确定性落到郡治城；不改变动态世界数值；重复运行幂等。
3. 规则测试：非相邻城池不可移动；相邻路线可移动；围城只能选择城池；城陷后郡/州控制权仍正确派生。
4. API/前端合同：地图负载使用真实城池 ID、坐标、驻军、城权和路线，没有名称别名或临时偏移依赖。
5. 回归：相关 Python 测试、前端 `node --test tests/*.test.ts` 与 `npm run build` 通过。

## 非目标

- 不改动最终州郡城的边界、名称或视觉设计。
- 不扩展 AI 行为、随机域、月度顺序、资源公式或外交规则。
- 不保留旧方案兼容入口。
