# SANGUO 核心闭环 UI 规格 v1

## 视觉原则

地图始终是游戏世界的底层；功能内容只以有限宽度的纸卷、档案条或抽屉落在其上。浅宣纸承担阅读，灰青表达结构与可行动，朱砂只表达提交、危急、月结和已确认。禁止深棕整屏底、无差别矩形卡片阵列、整页纯色遮罩和多个等权主按钮。

## 令牌

| 类别 | 规格 |
| --- | --- |
| 基础色 | 墨 `#263137`、浅纸 `#f7f2e7`、灰青 `#4f7075`、朱砂 `#9a4037`、警示褐 `#9d6d2c` |
| 语义 | 普通=淡墨；可行动=灰青；警示=低饱和褐；危急/最终提交=朱砂；完成=灰绿；禁用=低对比淡墨 |
| 字号 | 场景标题 `22–32px`；章节 `17px`；正文 `14px`；注释/印记 `12px` |
| 间距 | `8 / 12 / 18 / 28px` 四级；同一阅读卷不混用任意间距 |
| 阴影 | 只允许轻纸影 `0 16px 40px rgba(36,45,45,.16)`；地图档案可略强，禁用厚重黑影 |
| 边框 | 细墨线、灰青强调边、朱砂提交边；不使用全站统一粗金边 |
| 动效 | 悬浮、展开、切换、提交、月结均为 `120–240ms`；遵守 `prefers-reduced-motion` |

## 信息与操作层级

1. 每个场景只有一个可见主行动；使用朱砂印记或朱砂按钮。
2. 次操作使用灰青细线或浅纸按钮；返回、取消与辅助浏览使用无填充样式。
3. 指标默认呈现图标、数值和趋势；解释按需展开，不能把顶端做成仪表盘。
4. 风险、分歧、共识、已确认使用 `StatusMark` 与印记，不以大量彩色胶囊替代语义。

## 页面契约

| 页面 | 阅读优先级 | 唯一主行动 | 内容容器 |
| --- | --- | --- | --- |
| 局势枢纽 | 本月待议 → 朝局/情报 → 长期指标 | 当前最紧急决策 | 中央主卷 + 右侧编年列 |
| 地图 | 地理 → 地方档案 → 行动 | 以此为目标拟定方略 | 地图全底 + 侧档案 |
| 廷议 | 议题 → 席位/发言 → 建议 | 请诸臣陈议/采纳建议 | 三栏席次或中央对话卷 |
| 密谈 | 人物 → 对话 → 密令影响 | 下达密令 | 人物侧栏 + 对话卷 + 草拟区 |
| 军府方略 | 拟定 → 审阅 → 下达 | 最终下达方略 | 文书三步卷 |
| 月报 | 本月结论 → 已发生之事 → 天下余波 | 月结确认 | 纵向史册 |

## 无障碍与状态

- 弹窗由 `GameDialog` 承担焦点、Esc 和关闭行为；确认不可逆行为必须说明后果。
- 长文本、空状态、加载、错误、禁用、成功反馈均不得依赖颜色单独传达含义。
- 最小基准为窄桌面 `1024 × 768`；内容卷允许滚动，但不得遮挡底部导航或地图主操作。
