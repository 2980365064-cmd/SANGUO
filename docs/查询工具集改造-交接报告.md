## 六、架构决策摘要

1. **保留 `build_adjudication_pack()`** — 不删除，供 `_build_validation_context()` 内部使用
2. **查询工具全部只读** — 24 个工具只做 SELECT，AI 不能直接篡改世界状态
3. **双路径设计** — 基准路径（白名单快速通道）+ 自由路径（AI+工具）
4. **PROTOCOL_VERSION = 1** — 保持版本号不变
