## 未覆盖状态

- 审阅与颁令页：此存档没有草案，入口按设计禁用。
- 廷议进行中、建议库、月结不可逆确认、长文本/错误/加载：需要一份含草案、待议事件及请求状态的专用测试存档后补录；不能由前端伪造。

## 回归规则

- 后续同名场景必须继续以本目录的 `1440 × 900` 截图进行对照。
- 每次核心页面改造同时检查：文字溢出、点击区域、浮层层级、地图是否仍可从内容卷周围辨认。
- 窄桌面基线将在阶段六与固定的 `1024 × 768` 视口一并补录。
