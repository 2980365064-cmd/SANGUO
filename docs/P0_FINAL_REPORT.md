4. 审阅批次 ◄─────────────────────────────────────────┘
   └─ ReviewAndDecree 页面

5. 颁令 ◄─────────────────────────────────────────────┐
   └─ issueDirectiveBatch API                         │
                                                      │
6. 分阶段推演 ◄───────────────────────────────────────┘
   ├─ 后端：PhasedExecutor（5 个阶段）                 │
   └─ 前端：AdjudicationFlow（SSE 流式显示）           │

7. 每月总计 ◄─────────────────────────────────────────┐
   ├─ 批次执行结果展示                                 │

                                                      │

## 技术架构

### 后端架构
```
┌──────────────────────────────────────────────────────────┐
│                    后端架构（P0）                          │
└──────────────────────────────────────────────────────────┘

数据库层
├─ directive_drafts（方略草案）
├─ directive_batches（颁令批次）
└─ directive_batch_items（批次项目）

API 层
├─ /api/directive-drafts（草案 CRUD）
├─ /api/directive-batches（批次管理）
└─ /api/directive-batches/{id}/execute（SSE 执行）

执行层
└─ PhasedExecutor
   ├─ _execute_internal_phase()
   ├─ _execute_military_phase()
   ├─ _execute_diplomatic_phase()
   ├─ _execute_civilian_phase()
   └─ _execute_settlement_phase()
```

### 前端架构
```
┌──────────────────────────────────────────────────────────┐
│                    前端架构（P0）                          │
└──────────────────────────────────────────────────────────┘

状态管理层
└─ GameStore (React Context + useReducer)
   ├─ gameState
   ├─ currentPage
   ├─ drafts
   └─ currentBatch

页面层
├─ SituationHub（局势枢纽）
├─ CouncilHall（府堂廷议）
├─ SecretChat（单独密谈）
├─ MapDetail（地图详情）

组件层

API 层
├─ directiveDrafts.ts（草案 API）
└─ directiveBatches.ts（批次 API）
```

## 关键特性

### 1. 统一方略提交系统
- 所有改变世界的行为必须经过"军府方略"统一提交
- 地图、对话、任免、调防和外交只负责查阅、问策、生成草案

### 2. 分阶段推演
- 5 个执行阶段：内政 → 军事 → 外交 → 民生 → 核销
- SSE 流式实时显示执行过程
- 支持决策点裁断

### 3. 轻水墨视觉风格
- SceneShell 三层结构（场景图 + 调节层 + 内容层）
- 12+ 张背景图
- 统一的视觉组件

### 4. 模块化页面架构
- 8 个独立页面组件
- 统一的状态管理
- 清晰的页面路由
