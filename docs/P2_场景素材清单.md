# P2 场景素材清单

所有图像由 Claude 使用阿里百炼生成后放入 `web/public/assets/ui/`，再把 `sceneAssets.ts` 的状态改为 `ready` 并配置对应 token。

| 场景 | 目标文件 | 状态 | 安全区 |
| --- | --- | --- | --- |
| 战略地图 | `bg-map.webp` | 缺失 | 中央 60% 低对比，便于地图覆盖 |
| 审阅颁令 | `bg-review.webp` | 缺失 | 中央 60% 宣纸内容区 |
| 行军、水战、攻城、军营、使臣道路、灾荒推演 | `bg-adjudication-*.webp` | 缺失 | 中央 60% 低细节，边缘叙事陈设 |
| 雨夜急报、灾荒事件、丰收事件 | `bg-event-*.webp` | 缺失 | 中央 60% 低对比，正文可读 |

统一约束：轻水墨、东汉末年、无文字或水印、低饱和青灰赭石、宣纸质感、边缘有场景叙事物件；禁止现代 UI、强光效和密集人物特写。
