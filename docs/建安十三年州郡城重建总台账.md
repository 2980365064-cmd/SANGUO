# 建安十三年州郡城重建总台账

> **断代：建安十三年（208）八月。**
>
> 适用范围：除益州外的十二州。益州已进入单独校勘流程，本台账不得覆盖其已校对的城池锚点和边界决定。

## 不可变规则

1. 地图层级必须是 `州 → 郡 → 城`；运行时战略节点不是历史行政名册的替代物。
2. 每座城池必须只归属一郡；同郡城池以该郡手绘外界为母范围，确定性、无重叠地分割。
3. 历史上当年未独立设郡的地名只能作为所属郡的城/县显示，不能留下空白图块或伪造郡界。
4. 迁移旧档时只允许补入静态城池、同步名称/隶属、回收退役城粮并迁移悬空驻军/围城目标；不得改写控制权、兵力、人口、库存或回合事实。
5. 每州完成条件：当年郡名无重复、无后期郡名、城池无孤儿、城池辖区并集等于郡界、悬停描边复用原墨线。

| 日南 | 西卷 | 新增独立郡与郡治城 |

## 实施顺序

1. 先把每州 208 名册写入本台账并交叉核验，明确“新增郡 / 改名 / 退役城 / 迁隶城”。
2. 再将运行 `regions`、`strategic_nodes`、路线和 `administrative_cities` 做幂等旧档迁移。
3. 仅在事实层正确后，改 `annotatedMapData.ts` 与固定城位；缺少已校边界的郡不可用临时后台坐标冒充地理。
4. 每一批完成后跑行政迁移测试、地图分割测试、构建与浏览器核验。
