# 自由战术系统实现总结

## 项目概述

为《汉祚再兴·刘备传》实现了自由战术系统，允许玩家用自然语言描述战术意图，AI 基于盘面事实评估可行性并输出有界修正，而不是从固定菜单中选择。

## 核心改动

### 1. 战斗系统（ming_sim/battle.py）

#### 1.1 新增函数：`_validate_free_tactic()`
- **位置**：battle.py:444-620
- **功能**：校验 AI 的自由战术提案是否在边界内
- **安全检查**：
  - delta 边界裁剪：[-5, +15]
  - 无特性匹配时上限 +10，有特性匹配时上限 +15
  - actor 必须是参战统帅
  - feasibility=impossible 退回正面交锋
  - 禁止文本检查（reasoning 和 narrative）
  - 事实一致性检查

#### 1.2 新增函数：`_fact_supports_claim()`
- **位置**：battle.py:623-700
- **功能**：检查盘面事实是否支持 AI 的声称
- **检查项**：
  - epidemic_pressure（瘟疫）
  - supply（粮草不济）
  - morale（士气低落）
  - discipline（防备松懈）
  - weather（天气）

#### 1.3 修改函数：`build_battle_adjudication_pack()`
- **位置**：battle.py:327-420
- **改动**：
  - 新增 `regional_state` 字段（区域状态数据）
  - 新增 `defender_supply` 字段（防守方补给数据）
  - 用于事实一致性检查

#### 1.4 修改函数：`validate_battle_ai_choice()`
- **位置**：battle.py:631-650
- **改动**：
  - 支持双路径：基准路径（`tactic` 字段）和自由路径（`tactic_name` 字段）
  - 向后兼容：旧代码仍可使用

## 设计原则

### 1. 玩家是决策者
- 玩家用自然语言描述战术意图
- AI 负责评估可行性和执行细节
- 玩家不需要从固定菜单中选择

### 2. 基于事实
- AI 的评估必须基于盘面事实
- 不能凭空编造条件（如"瘟疫"需要 epidemic_pressure ≥ 60）
- 裁决包提供所有必要的事实数据

### 3. 安全边界
- delta 严格限制在 [-5, +15]
- 禁止文本检查（不能写死亡、领土变化等）
- 不可行方案自动退回正面交锋
- 所有检查都有测试覆盖

### 4. 确定性随机
- 同种子同输入，结果完全相同
- 自由路径和基准路径使用相同的随机机制
- 支持读档重放

## 使用示例

### 基准路径（旧方式）
```python
ai_choice = {
    "tactic": "水战突击",  # 必须在 TACTIC_RULES 中
    "actor": "关羽",
    "narrative": "关羽率水军突击曹军。"
}
```

### 自由路径（新方式）
```python
ai_choice = {
    "tactic_name": "连环火计",  # 自由命名
    "actor": "关羽",
    "delta": 12,  # AI 评估的修正值
    "feasibility": "high",  # AI 评估的可行性
    "reasoning": [
        "关羽水战特性 +10",
        "曹军连环船易被火攻 +5",
        "风向有利 +3"
    ],
    "narrative": "关羽借东风放火，曹军连环船焚尽，大败而逃。"
}
```
