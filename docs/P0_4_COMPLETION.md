## 技术细节

### 状态管理
- 使用 `useDrafts()` hook 管理草案列表
- 使用 `useCurrentBatch()` hook 管理当前批次
- 本地状态：selectedDraftIds（选择的草案 ID 集合）、validationResults（校验结果）

### API 调用流程
1. **加载草案**：`listDirectiveDrafts({ turn, status: 'validated' })`
2. **批量校验**：循环调用 `validateDirectiveDraft(id)`
3. **创建批次**：`createDirectiveBatch({ batch_title, draft_ids, decree_text })`
4. **颁令**：`issueDirectiveBatch(id)`

### 错误处理
- API 错误：显示错误消息
- 表单验证：必填字段检查（批次标题）
- 选择验证：至少选择一个草案

### 用户体验优化
- 加载状态：显示"加载中..."
- 禁用按钮：操作进行中禁用相关按钮
- 确认对话框：删除前确认
- 状态徽章：用颜色区分不同状态
