# Phase 0.3 视觉素材生成指南

## 概述
需要生成 30-40 张背景图片，用于轻水墨三国风格的各个场景。

## 生成工具
- **推荐工具**: 阿里百炼 (Alibaba Cloud Bailian)
- **备选工具**: Midjourney, DALL-E 3, Stable Diffusion XL
- **输出格式**: PNG (源文件) + WebP (优化后用于 Web)
- **分辨率**: 1920x1080 (16:9) 或 2560x1440 (16:9)

## 统一风格约束

### 必须包含
- 东汉末年至三国早期时代背景
- 轻水墨风格，淡设色
- 宣纸纤维质感
- 木案、竹简、墨迹元素
- 朱印点缀
- 低饱和青灰与赭石色调
- 明确的内容安全区（中央 60% 区域留白）

### 禁止出现
- 现代 UI 元素
- 任何文字、水印
- 印刷体标题
- 夸张游戏海报光效
- 赛博朋克色彩
- 浓黑大面积泼墨
- 过强景深
- 密集人物脸部特写

### 构图要求
- 全幅场景背景
- 内容安全区：中央 60% 区域保持低细节、低对比度
- 边缘可有装饰性元素（竹简、木案边缘、墨迹）
- 避免视觉焦点过于集中

## 生成流程

### 第一步：批量生成（每类 3 张备选）
1. 使用上述提示词在阿里百炼生成图片
2. 每张生成 3 个变体
3. 保存为 PNG 格式，命名规则：`{scene_name}_v{1-3}.png`

### 第二步：筛选
1. 五情境可读性检查：
   - 桌面宽屏 (1920x1080)
   - 窄屏 (1366x768)
   - 文字密集场景
   - 滚动内容场景
   - 模态叠层场景
2. 每类选择最佳 1 张

### 第三步：优化
1. 使用 ImageMagick 或在线工具转换为 WebP
2. 压缩至 200-500KB（平衡质量与加载速度）
3. 命名规则：`{scene_name}.webp`

### 第四步：部署
1. 复制到 `web/public/assets/ui/` 目录
2. 更新 CSS 变量引用（已在 `tokens/colors.css` 中声明）
3. 验证构建无警告
