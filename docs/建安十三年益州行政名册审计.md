# 建安十三年益州行政名册审计

> 适用时间：建安十三年（208）八月。本文是天下舆图“州—郡—城”事实层的校勘底稿；未完成校勘的地理块不得再被当作既成郡显示。

## 已确认的纠错结论

| 当前图层问题 | 208 年事实 | 数据处理 |
| --- | --- | --- |
| 夜郎与且兰各画成一个“牂牁郡” | 两者应归同一牂牁郡；夜郎、且兰是城/县级落点 | 以现有兼容节点 `yelang` 表示牂牁郡，保留两座城并以同一郡界分区 |
| 阆中作为巴郡普通城退役 | 建安六年后阆中为巴西郡治 | 恢复阆中；现阶段以兼容运行 id `zitong` 承载巴西郡，不得占用巴郡（江州）辖区 |
| 鱼复/白帝显示为“永安” | 章武二年（222）才改鱼复县为永安县 | 208 地图显示“鱼复／白帝”；`永安`仅可作为后续年代演变名 |
| 梓潼显示为既成郡 | 梓潼郡置于建安二十二年（217） | 208 时退回广汉辖内城邑，不画独立郡界 |
| 上庸显示为益州既成郡 | 可确证的上庸郡建制为魏景初元年（237），且属荆州 | 208 时不画为益州独立郡；另行校其县级归属 |

## 208 年益州郡级基线

东汉中后期的益州名册可确认含蜀、巴、汉中、广汉、犍为、牂牁、越嶲、益州、永昌及属国体系；刘璋在建安六年完成三巴调整，建安十三年必须至少分别保留：

- 巴郡：治江州。
- 巴西郡：治阆中。
- 巴东郡：治鱼复／白帝。
- 牂牁郡：夜郎、且兰均为其辖内城邑，不能重复成郡。
- 汉中、广汉、蜀、犍为、越嶲、益州、永昌及当时仍存的属国体系：在补齐各自城池与边界前，不得以蜀汉后期郡名替代。

## 实施顺序

1. 已完成首轮名册与存档迁移：阆中恢复为巴西郡治，鱼复／白帝改回巴东郡治，梓潼、上庸的独立城池记录退役，夜郎、且兰归同一牂牁郡。旧运行 id 的彻底改名须与存档、路线和势力剧本一并迁移，不能仅改一处字符串。
2. 再改边界：巴郡、巴西、巴东、牂牁各只保留一条郡外界；城池只在所属郡界内不规则分割。
3. 逐郡补齐静态城位，所有锚点均写入事实数据；禁用后端临时坐标作为地图地理来源。
4. 每一郡以“城池无重叠、并集等于郡界、无重复郡名、点击与高亮一致”为验收。
