# Implementation checklist

Before code: identify the artifact, player decision, visual focus, reading hierarchy, spatial regions, material layers, controls, responsive states, and available project assets.

After code: check that the first glance is the identity or decision—not borders/buttons/numbers; information is not equal-sized modules; paper/ink/seal treatment is structural; whitespace survives at narrow widths; interactions remain usable; no dashboard/card/chat-bubble patterns remain.

If a visual claim cannot be verified in a browser, report that limitation precisely rather than treating build success as visual QA.
