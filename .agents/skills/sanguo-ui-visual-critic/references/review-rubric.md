# Visual review rubric

Pass evidence: state identity and core judgment dominate the composition; supporting data follows the reading path; paper/ink/seal layers form the interface structure; restrained empty space makes the document readable; controls fit the artifact.

Failure evidence: every item is an equal rounded card; statistics form a dashboard grid; dialogue uses left/right bubbles; historical style is only beige/brown; decoration is pasted on rather than integrated; typography and spacing read as a generic web app.
